## 投稿1｜食料CPI 42.3%上昇

```
総務省の食料CPI（2020年＝100）。

2025年：125.8

12年で約42.3%上昇。

生活扶助の食費相当額がこの間どう変わったか、厚労省は公開していない。物価が4割上がった事実を、制度は直視しているか。

#くらしの最低線
```

## 投稿2｜家賃は住宅扶助、食費は生活扶助

**投稿予定：8月13日（水）**

```
「生活保護で家賃も出るのに」と思っている人へ。

家賃 → 住宅扶助（上限内で実費支給）
食費 → 生活扶助（定額、被服・光熱水費と一括）

別の扶助、別の仕組み。食料が42.3%上がっても、食費部分の算定根拠は公開されない。家賃と食費を混ぜたまま議論しても、制度は動かない。

#くらしの最低線
```

## 投稿3｜恒久ルールの有無という優先順位

**投稿予定：8月16日（土）**

```
企業支援 → AI・半導体に7年10兆円超の計画
公務員給与 → 民間と毎年比較し改定（2025年は3.3%）
最低生活の食費 → 月1,500円の特例加算、1年限り

計画がある。比較がある。でも食費には恒久ルールがない。

「財源がない」ではなく、優先順位の問題。

#くらしの最低線
```

```
雇われているだけで、価値が生まれるわけではない。
```
