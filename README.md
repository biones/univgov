## 🚫 なぜ「選挙」と「国家司法」を拒絶するのか？

近代国家の「選挙（多数決）」と「司法独占」は、正義の実現ではなく**責任転嫁と支配の維持装置**です。

```
┌─────────────────────────────────────────────────────────────┐
│               近代国家の「選挙」という免責トラップ          │
├─────────────────────────────────────────────────────────────┤
│ 【投票した場合】                                            │
│  →「お前たちが選んだ代表が決めた法律だから、従うのは当然だ」│
│ 【投票しなかった場合】                                      │
│  →「投票も行かない無責任な奴に、文句を言う資格はない」      │
│  ★ 結果：どんな悪法・重税も「国民の自己責任」にロンダリング │
└─────────────────────────────────────────────────────────────┘
```

宇宙法は以下の代替メカニズムによって法を統治します：

1. **個別オプトイン優先**: 全員を単一のルールに従わせるのではなく、個別のプラグイン規約として運用。
2. **危害の反証可能性テスト**: 具体的・客観的な危害データのない規制提案（道徳や感情に基づくもの）はCIで自動却下。
3. **フューチャキー（Futarchy）**: 政策の効果予測を予測市場で実証検証。
4. **義務的サンセット**: すべての法は1〜3年で自動失効（データによる再承認がなければRevert）。
5. **合法的フォーク権（Right to Fork）**: 意見の対立は多数決で屈服させず、平和的にブランチを分岐・並立させて市民が選ぶ。

## 🛠️ 参加・改訂・フォークの方法

- **Issueの提起**: 具体的危害のデータ、解決したい問題、代替案を明記してIssueを作成します。
- **Pull Request（PR）**: [宇宙法マージプロトコル（SLMP-1）](./SPACE_LAW_MERGE_PROTOCOL.md) に基づき、差分・根拠・失効期限を付与して提出します。
- **Fork（分岐）**: 統治方針や条文に根本的不一致がある場合、誰でも本リポジトリを自由にフォークして独自のガバナンスブランチを立ち上げることができます。報復や妨害は本法第20条により固く禁じられています。
