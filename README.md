# 🌌 宇宙法典 ＆ Gitマージプロトコル（Space Law Code & SLMP-1）

> **国家を「運命の檻」から「選べる部品」へ。**  
> 近代国家が独占してきた「領土・軍事暴力・選挙・国家司法・通貨・心の帰属」の強制的な抱き合わせを解体し、法学・経済学・政治哲学の叡智を結集して構築された、非領土型Gitネイティブ法規範体系。

### 第0編：根本規範と基本的人権（Charter & Inviolable Rights）
- **[第0編 第1条【帰属選択の自由と多重所属】](./laws/00_fundamental/01_freedom_of_allegiance.md)** —— 出生地や国籍による忠誠強制を拒絶。心の国籍の自己選択。
- **[第0編 第2条【非領土性と管轄の非独占】](./laws/00_fundamental/02_non_territoriality.md)** —— 土地の軍事囲い込みを否定。合意に基づくプロトコル管轄。
- **[第0編 第3条【危害原則と最小強制】](./laws/00_fundamental/03_harm_principle.md)** —— 他者への具体的危害防止以外の強制を禁止（パターナリズムの排除）。
- **[第0編 第4条【生命・意識・身体の不可侵権】](./laws/00_fundamental/04_inviolability_of_life.md)** —— 死刑・拷問・洗脳の絶対禁止。生命維持インフラの不可侵。
- **[第0編 第5条【無条件退出権とデータ可搬性】](./laws/00_fundamental/05_right_of_exit.md)** —— ワンクリック完全EXITと全データ・残高の持ち出し権利。

### 第1編：宇宙コモンズ・軌道環境・資源法（Space Commons & Environmental Stewardship）
- **[第1編 第6条【天体・軌道・周波数の非領有と共同利用】](./laws/01_commons_environment/06_celestial_commons.md)** —— 月・火星・LEO軌道・電波帯域の非領有・共有財保護。
- **[第1編 第7条【資源採取権とオストロム型多中心管理】](./laws/01_commons_environment/07_resource_usufruct.md)** —— 労働用益権（Usufruct）の承認と当事者自治（コモンズ8原則）。
- **[第1編 第8条【軌道デブリ責任とデブリ預託返還債（ケスラー債）】](./laws/01_commons_environment/08_debris_liability.md)** —— 打上げ時デブリ回収債券拠出による外部性内部化。
- **[第1編 第9条【惑星保護と未知生命系保全】](./laws/01_commons_environment/09_planetary_protection.md)** —— 前方・後方汚染防止と未知生命区域の科学的聖域化。

### 第2編：経済自律・通貨・契約法（Economic Autonomy, Currency & Smart Contracts）
- **[第2編 第10条【通貨競合と初期基本給（UNI Protocol）】](./laws/02_economy_currency/10_monetary_freedom.md)** —— 法定通貨強制の拒絶、全市民への $10^6\text{ UNI}$ 初期基本給無条件交付。
- **[第2編 第11条【契約自由とスマート仲裁プロトコル】](./laws/02_economy_currency/11_contractual_autonomy.md)** —— スマートコントラクト（Lex Contractus）と分散仲裁の承認。
- **[第2編 第12条【外部性の内部化と非搾取的公共財調達】](./laws/02_economy_currency/12_pigovian_public_goods.md)** —— 強制徴税を廃止。ピグー利用料とクアドラティック・ファンディング（QF）。
- **[第2編 第13条【基盤独占の禁止と相互運用性の義務】](./laws/02_economy_currency/13_anti_monopoly.md)** —— 生命維持・通信・ハッチ結合規格のオープン化と囲い込み禁止。

### 第3編：紛争解決・司法・修復的正義（Dispute Resolution & Restorative Justice）
- **[第3編 第14条【国家司法の廃止・合意管轄と分散型裁判所】](./laws/03_dispute_justice/14_consensual_arbitration.md)** —— 裁判権独占・天下りの解体。当事者合意による分散型仲裁オラクル。

## 🔀 宇宙法マージプロトコル（SLMP-1）

```
┌─────────────────────────────────────────────────────────────┐
│          近代国家の「選挙（多数決）」という免責トラップ     │
├─────────────────────────────────────────────────────────────┤
│ 【投票した場合】                                            │
│  →「代表が選ばれたのだから従え（民意の独占）」              │
│ 【投票しなかった場合】                                      │
│  →「投票も行かない奴に文句を言う資格はない（自己責任）」    │
│  ★ 結果：悪法・重税・利権の責任を国民個人へロンダリング     │
└─────────────────────────────────────────────────────────────┘
```

本法典の改訂・マージは、選挙や多数決ではなく **[宇宙法マージプロトコル（SLMP-1）](./SPACE_LAW_MERGE_PROTOCOL.md)** に従って行われます。

1. **非強制・個別化の優先（Subsidiarity）**: 全体強制（Core）を避け、オプトイン・プラグインとして実装。
2. **危害の反証可能性テスト**: 「客観的危害データ」のない規制提案（道徳・感情・パターナリズム）はCIで自動却下。
3. **フューチャキー（Futarchy）**: 政策の効果予測を予測市場で検証。
4. **義務的サンセット（TTL）**: 全法規に有効期限を付与。事後検証なき延長は自動リバート（Revert）。
5. **合法的フォーク権（Fork Over Merge）**: 意見の対立は多数決で屈服させず、平和的にブランチを分岐（Fork）。

## 🛠️ 特定の条文に突っ込む（PR / Issueの送り方）

1. 上記のクイックアクセス表から、突っ込みたい条文ファイル（例: [`laws/02_economy_currency/10_monetary_freedom.md`](./laws/02_economy_currency/10_monetary_freedom.md)）をクリック。
2. GitHubの鉛筆アイコン（Edit this file）を押して編集、またはローカルで修正。
3. [SLMP-1](./SPACE_LAW_MERGE_PROTOCOL.md) に基づき、**「具体的危害の証拠」「代替案」「サンセット期日」**を明記してPull Requestを作成。
4. 条文の議論は、タイトルに `[Art. 2-10]` 等を付けて [Issue](../../issues) を立ててください。
