## 🛠️ 条文の修正提案（PR）の提出方法

改訂提案は、[宇宙法マージプロトコル（SLMP-1）](../SPACE_LAW_MERGE_PROTOCOL.md) に従って提出してください。

1. 本リポジトリを Fork またはブランチ作成。
2. 対象の条文ファイル（例: `laws/02_economy_currency/10_monetary_freedom.md`）を編集。
3. PRを作成し、**「具体的危害の反証データ」「代替案」「サンセット期日」**を明記。
